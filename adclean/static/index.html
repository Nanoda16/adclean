    自动清洗

    会删掉的东西：
    · 整行广告（网页标签 / 网址 / 群号 / 上传者水印 / 章尾求票）
    · 句内插入的乱码、零宽字符、异常符号
    没有插入痕迹的书一个字都不删；原文件不会被覆盖。
    默认开启。会把繁体字换成简体字（属于字形改写）；取消勾选则保留原字形， 简繁混排的书可能把繁体正文误判成插入字删掉。

    审计报告

    LLM 连接 OpenAI 兼容

    任意 OpenAI 兼容服务：官方 / 中转站 / 本地 Ollama、vLLM、LM Studio。 地址填到 /v1 即可。API Key 只存本机，不回显、不写日志。
    调用参数（默认已按稳妥值设置）
    「单次上限」= 一次运行最多送审多少条；0 = 不限。 想控制花费就先设小一点（如 50），确认质量后再放开。

    执行 LLM 审查 写回 + 完整日志

    把审查队列发给 LLM 复核，决策自动写回。默认只允许删除，不允许替换或插入。
    每条决策记入 changelog，另存一份未应用 LLM 的 *.auto.txt 供对比回滚。
    没送完怎么办：把下面「单次上限」改成 0（不限）再跑一次即可全部处理。
